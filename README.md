# 🏆 دوري أبطال الصعيد - مدرب الصعيد أونلاين

نسخة الويب التفاعلية (PWA) الرسمية لإدارة أندية ومراكز شباب الصعيد.. العِمّة، الشاي المغربي، التكتيكات النارية، وسوق الانتقالات! 🔥🏺

## 🌟 مميزات اللعبة
- **وضع الأونلاين الحقيقي**: متصل بـ Firebase Firestore لتخزين بيانات المدربين، مواجهات الأصدقاء ("أولاد العم")، والمباريات الودية.
- **إدارة كاملة**: تشكيلة الفريق، شراء وبيع اللاعبين، تطوير الملاعب، وكروت معاينة المدربين.
- **محاكاة المباريات اللحظية**: تكتيكات أثناء الماتش (مصيدة التسلل، الشوط الصاروخي، والهجوم الكاسح).

---

## 🚀 طريقة التشغيل أونلاين (GitHub Pages)
1. قم برفع ملف `Saidi_Manager_Online_PWA_Complete.html` إلى مستودع GitHub الخاص بك.
2. اذهب إلى **Settings** ثم **Pages** في مستودعك على GitHub.
3. تحت قسم **Build and deployment**، اختر الفرع **`main`** ثم اضغط **Save**.
4. خلال دقيقة سيظهر لك رابط موقعك المباشر (`.github.io`) لتلعب أونلاين فوراً!

---

## 🛠️ إعدادات Firebase
المشروع مربوط بقاعدة بيانات Firebase (`saidi-manager-96b8b`). تأكد من ضبط قواعد الأمان (Firestore Rules) على وضع القراءة والكتابة العامة (`allow read, write: if true;`) لضمان ظهور المدربين لبعضهم لحظياً.
